TITLE
오프라인 PDF 뷰어 및 도구

SHORT DESCRIPTION
인터넷 없이 PDF를 읽고 기기에서 병합, 분할, 압축하세요.

FULL DESCRIPTION
문서를 클라우드에 업로드하지 않고 PDF 파일을 열고 읽고 관리하세요. 오프라인 PDF 뷰어 및 도구는 Android 기기에서 직접 작동합니다. 계정이나 로그인은 필요하지 않습니다. 인터넷 연결이 없어도 저장된 PDF 읽기, PDF 병합, 페이지 분할, PDF 압축을 사용할 수 있습니다.

오프라인 PDF 읽기

오프라인 PDF 리더 및 PDF 뷰어로 사용할 수 있습니다. 연속으로 스크롤하거나 한 페이지씩 넘기고, 한 페이지 보기를 고정하거나 원하는 페이지 번호로 바로 이동하세요. 다크 모드는 PDF 페이지 자체의 색상을 반전해 야간 독서를 편안하게 합니다. 앱은 마지막으로 읽은 페이지를 기억합니다.

암호로 보호된 PDF는 암호를 입력해 열 수 있습니다. 채팅, 이메일 또는 파일 관리자에서 받은 PDF도 바로 열 수 있습니다. 인터넷에 연결된 상태에서는 PDF 링크를 앱으로 직접 열 수 있습니다.

PDF 압축 및 파일 크기 줄이기

이메일 전송, 업로드 용량 제한 충족 또는 저장 공간 절약이 필요할 때 휴대전화에서 PDF 파일 크기를 줄이세요. 앱은 먼저 품질 손실 없는 재패키징을 시도합니다. 더 압축할 수 있으면 PDF 안의 이미지를 다시 인코딩하도록 제안하며, 사용자의 허락을 받은 뒤에만 실행합니다.

PDF 압축은 스캔 문서와 이미지가 많은 파일에서 가장 효과적입니다. 실제 측정 예시에서 3.9MB 스캔 PDF가 248KB로 줄어 94% 작아졌습니다. 결과는 문서마다 다릅니다. 텍스트만 있는 PDF는 이미 최적화되어 있을 수 있으며, 더 줄일 수 없을 때 앱이 이를 명확히 알려 줍니다. 압축 전후 크기도 표시됩니다.

PDF 병합, PDF 분할 및 페이지 추출

여러 PDF를 하나의 문서로 병합하세요. 선택한 페이지에서 PDF를 두 파일로 나누고, 원하는 페이지만 새 PDF로 추출하거나 복사본에서 불필요한 페이지를 삭제할 수 있습니다. 원본 파일은 덮어쓰지 않으며 각 도구가 새 결과 파일을 만듭니다.

페이지 정리 및 PDF 만들기

페이지 순서를 원하는 대로 바꾸고, 선택한 페이지를 90도 회전하고, 모든 페이지에 대각선 텍스트 워터마크를 추가하세요. 완료한 문서는 Android 인쇄 창에서 인쇄하거나 PDF로 저장할 수 있습니다.

JPG 및 PNG 이미지를 하나의 PDF로 변환하고, 사진을 찍어 PDF로 저장하거나, 제목과 입력한 텍스트로 간단한 PDF를 만들 수 있습니다. 모든 생성 작업은 기기에서 로컬로 처리됩니다.

숨겨진 PDF 메타데이터 삭제

PDF에는 제목, 작성자, 주제, 키워드, 제작 프로그램, 날짜 및 XMP 메타데이터처럼 페이지에 보이지 않는 정보가 포함될 수 있습니다. 메타데이터 정리 도구는 공유 전 새 복사본에서 이 항목을 삭제합니다.

기기 내 라이브러리와 파일 개인정보 보호

열어 본 PDF를 기기 내 라이브러리에 보관하고 즐겨찾기에 추가하거나 파일 이름으로 검색하세요. 설정에서 로컬 복사본, 읽기 기록 및 도구 사용 카운터를 지울 수 있습니다.

읽기, 병합, 분할, 압축, 페이지 정리 및 메타데이터 삭제는 휴대전화에서 실행됩니다. PDF 내용은 개발자 서버에 업로드되지 않습니다. 따라서 비행기, 지하철 또는 신호가 없는 곳에서도 핵심 리더와 도구를 사용할 수 있습니다. 인터페이스는 24개 언어를 지원합니다.

명확한 제한 사항

OCR, 기존 PDF 내부 텍스트 편집, 전자 서명, PDF를 Word로 변환하는 기능은 제공하지 않습니다. 현재 카메라는 문서당 사진 한 장을 만들며 다중 페이지 스캔은 지원하지 않습니다.

앱은 광고로 운영되며 구독은 없습니다. 선택형 보상 동영상을 보면 10분 동안 광고 없이 사용할 수 있습니다. 결제나 필수 동영상 뒤에 잠긴 PDF 도구는 없습니다.
