# Yasal site eşitleme notu

Bu klasör, uygulamanın gizlilik politikası ve `app-ads.txt` için kaynak kopyadır. Canlı site ayrı ve public `MrZekai/MrZekai.github.io` deposunun kökünden yayınlanır.

`docs/index.html`, `docs/privacy-policy.html` veya `docs/app-ads.txt` değiştiğinde aynı dosyaları canlı site deposuna kopyalayıp commit/push etmek zorunludur. Ardından şu adresler doğrulanmalıdır:

- https://mrzekai.github.io/
- https://mrzekai.github.io/privacy-policy.html
- https://mrzekai.github.io/app-ads.txt

Play Store için kullanılan gizlilik politikası URL’si ve AdMob için kullanılan `app-ads.txt` alan adı bu kök adrestir.
