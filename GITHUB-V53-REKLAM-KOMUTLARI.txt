7) QA APK'yı bekleyin ve GERÇEK CİHAZDA test edin
--------------------------------------------------------------------------------

GitHub Actions > Expo Android Build çalışmasını bekleyin (~20-40 dk).

APK, Actions artifact yerine TASLAK GitHub Release olarak teslim ediliyor:
  GitHub > Releases > Drafts > "PDF Okuyucu CI Delivery #<run_number>"
İçinden <run_number>-apk__release__app-release.apk dosyasını indirin.

QA APK'da yalnızca Google demo reklamları görünür, gerçek reklam görünmez.
Bu bilinçlidir: kendi reklamlarınıza tıklamak AdMob hesabınızı riske atar.

Test listesi:
  [ ] Uygulamayı 3 kez kapatıp açın -> 3. açılışta demo açılış reklamı gelmeli
  [ ] WhatsApp/Drive'dan bir PDF'e dokunun -> AÇILIŞ REKLAMI GELMEMELİ, belge açılmalı
  [ ] Üç kez araç çalıştırın (birleştir/döndür) -> 3. işlem sonrası "Bitti" deyince geçiş reklamı
  [ ] Aynı işlemde "Aç" deyin -> reklam GELMEMELİ, okuyucu açılmalı
  [ ] Ayarlar > "30 dakika reklamsız" -> demo ödüllü video, sonra banner dahil tüm reklamlar kaybolmalı
  [ ] 30 dakika dolunca veya uygulamayı tekrar açınca banner geri gelmeli
  [ ] 20 MB üstü bir PDF içe aktarın -> arayüz donmamalı
  [ ] 13 dosya seçip birleştirmeyi deneyin -> nazik "çok büyük" hatası, çökme yok

--------------------------------------------------------------------------------
8) AAB üretin (elle tetiklenir)
--------------------------------------------------------------------------------

QA testi geçmeden bu adımı çalıştırmayın.

GitHub > Actions > "Expo Android Build" > Run workflow
  build_release  : true
  release_target : closed_test    (kapalı test için)
                   production     (Play production için)

closed_test seçilirse AAB Google demo reklam birimlerini kullanır ve workflow
production birimlerinin sızmadığını doğrular. production seçilirse gerçek
birimler kullanılır ve canlı gizlilik politikası ile app-ads.txt sayfaları
kontrol edilir; bu sayfalar erişilemezse build bilinçli olarak durur.

AAB yine taslak GitHub Release içinde gelir:
  <run_number>-bundle__release__app-release.aab

versionCode elle ayarlanmaz; workflow github.run_number değerini kullanır.
Bir önceki yayın 52 idi, sıradaki çalıştırma 53 üretir.
