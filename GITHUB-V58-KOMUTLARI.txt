Bu surum tek bir isi yapiyor: gecis reklaminin neden hic cikmadigini
duzeltiyor. Yeni ozellik yok, yeni izin yok, yeni veri toplama yok.

Cihazdaki tanilama ekrani sunu gosterdi:
  tool runs: 5  /  interstitial prepared: YES  /  interstitials: 0
Yani reklam yuklenmisti ama gosterim hic cagrilmadi. Sebep: sonuc
penceresinde "Ac" butonu reklami tamamen iptal ediyordu.

package.json / package-lock.json DEGISMEDI. npm ci gerekmez.

================================================================================
ADIM 3 - COMMIT VE PUSH
================================================================================

git -c core.safecrlf=false add -A

git --no-pager diff --cached --stat

MUST="lib/adGate.ts app/(tabs)/tools.tsx components/AppOpenAdController.tsx scripts/validate-release.mjs docs/privacy-policy.html"
OK=1
for f in $MUST; do
  if ! git --no-pager diff --cached --name-only | grep -Fxq "$f"; then
    echo "EKSIK: $f"
    OK=0
  fi
done

if [ "$OK" -eq 1 ]; then
  git commit -m "Gecis reklamini sessiz kotalardan kurtar, tempoyu AdMob paneline tasi"
  git push origin main
  echo "=== PUSH TAMAM ==="
else
  echo "=== DURUN: kritik dosyalar hazirlanmamis. Commit atilmadi. ==="
fi

Push bir QA APK derlemesi baslatir. Yesil olmasini bekleyin.

================================================================================
ADIM 4 - QA APK ILE CIHAZ TESTI   (bu adimi ATLAMAYIN)
================================================================================

Draft GitHub Release icindeki APK'yi telefona kurun, sonra sirayla:

  Ayarlar > Uygulamalar > PDF: Okuyucu > Zorla durdur + Verileri temizle

  TEST 1 - GECIS REKLAMI, "Bitti" yolu
    1. Uygulamayi ac
    2. Araclar sekmesine gec, 5 saniye bekle (reklam onden yukleniyor)
    3. Herhangi bir arac calistir (en kolayi: PDF dondur)
    4. Cikan pencerede "Bitti"ye bas
    5. GECIS REKLAMI CIKMALI

  TEST 2 - GECIS REKLAMI, "Ac" yolu  (eskiden calismayan yol)
    1. En az 60 saniye bekle
    2. Araclar > bir arac calistir
    3. Cikan pencerede "Ac"a bas, PDF acilsin
    4. Geri tusuna bas, Araclar ekranina don
    5. GECIS REKLAMI CIKMALI

  TEST 3 - ODULLU REKLAM
    1. Ana Sayfa > "10 dakika reklamsiz" seridine bas
    2. Reklam izlenince banner kaybolmali
    3. Serit "Reklamsiz sure suruyor: 10 dakika kaldi" haline gelmeli
    4. Bu 10 dakika boyunca gecis reklami CIKMAMALI (dogru davranis)

  TEST 4 - ACILIS REKLAMI
    1. Uygulamayi tamamen kapat, tekrar ac  (2. acilistan itibaren)
    2. ACILIS REKLAMI CIKMALI
    3. Simdi baska bir uygulamadan bir PDF dosyasina tikla
    4. ACILIS REKLAMI CIKMAMALI, dogrudan PDF acilmali  <- politika korumasi

  HERHANGI BIRI TUTMAZSA:
    Ayarlar ekranini en asagi kaydir. Kirmizi "Kutuphaneyi temizle"
    bolumunun de altinda, sayfanin en sonunda, ortalanmis kucuk gri bir
    satir var: basinda (i) ikonu, yaninda uygulama adi ve "Expo SDK 57"
    yaziyor. O gri satira arka arkaya 7 kez dokun.

    Acilan pencerenin en alt satiri artik dogrudan sonucu yaziyor:
      "SONUC: Gecis reklami cikabilir"        -> sart yok, reklam gelmeli
      "SONUC: 60 sn dolmadi, biraz bekleyin"  -> normal, bekleyin
      "SONUC: Reklamsiz sure acik, ..."       -> odul devrede, normal

    Ekran goruntusunu gonderin.
