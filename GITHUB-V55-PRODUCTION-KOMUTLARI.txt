ADIM 2 — KONTROLLER
================================================================================

git -c core.safecrlf=false --no-pager diff --check

kontrol ediyor. "Release kontrolü başarılı" görmeden devam etmeyin.

================================================================================
ADIM 4 — PRODUCTION AAB
================================================================================

Once QA derlemesi yesile donsun.

GitHub > Actions > Expo Android Build > Run workflow
  build_release  : true
  release_target : production

Bu hedefte workflow sunlari dogrular ve biri bile tutmazsa AAB uretmez:
  - Canli gizlilik politikasi erisilebilir mi, uygulama adini ve dort reklam
    biciminin beyanini iceriyor mu
  - Canli app-ads.txt dogru satiri iceriyor mu
  - AAB icinde GERCEK reklam birimleri var mi, demo birim sizmis mi
  - AAB upload anahtariyla imzalanmis mi, debug sertifikasi degil mi
  - 64-bit native kitapliklar 16 KB hizali mi

AAB yine taslak GitHub Release icinde gelir:
  <run_number>-bundle__release__app-release.aab

Magaza ekran goruntuleri eski arayuz hashindeyse workflow UYARI verir ama
durmaz. Ana sayfa degistigi icin screenshot-01-home yenilenmeli.
